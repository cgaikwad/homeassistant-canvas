# Home Assistant Add-on Repository: Canvas Dashboard

Add-ons for pulling Canvas LMS (school) grades/assignments into Home
Assistant via a parent Observer account.

## Add this repository

**Settings → Add-ons → Add-on Store → ⋮ (top right) → Repositories**, paste:

```
https://github.com/cgaikwad/homeassistant-canvas
```

Then find **Canvas Dashboard** under the newly added repository's add-ons and
install it. See [`canvas_dashboard/README.md`](canvas_dashboard/README.md)
for configuration and usage.

> Note: this is a Supervisor **add-on** repository (Settings → Add-ons →
> Add-on Store → Repositories), not a HACS repository — HACS covers
> integrations/frontend/themes, not Supervisor add-ons. The install step is a
> one-time paste either way.
